# Houses Catalise

Novo aplicativo mobile-first da Catalise Church para registro e acompanhamento das Houses.

## Arquitetura
- Front-end estático: HTML, CSS e JavaScript
- Backend: Supabase / Edge Function `houses-api`
- Banco: Redes, Houses, registros, cuidado pastoral, materiais e perfis
- Segurança: RLS e acesso individual por token de House

## House inicial
- Rede 04
- H-0119 • Neto e Patricia

## Publicação
O projeto está preparado para GitHub Pages. Em Settings > Pages, selecione **Deploy from a branch**, branch **main**, pasta **/(root)**.

O aplicativo antigo em Google Apps Script não é alterado por este projeto.
